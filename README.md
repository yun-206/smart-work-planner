# K-pop 해외공연 데이터 도구

원본 데이터로 박사님 양식의 결과 엑셀을 만들고(순위 자동 산정), 규칙 위반을 검사하는 웹페이지입니다.
**파일은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.**

## 탭 구성

| 탭 | 하는 일 |
|---|---|
| ① 조립·순위 | 원본 데이터(+업데이트 파일) → 결과 엑셀(해외 공연 현황 / (2) / 연도별 아티스트 목록 / 변수 설명). 자동 순위 연도는 순위를 다시 계산해 상위 N팀만 상세 수록, [예정]·[일부 예정] 태그와 색칠, 수식(qt·capacity*days) 자동. 만들자마자 ② 검증 실행 |
| ② 검증 | 결과 엑셀의 규칙 위반 검사 (21개 데이터 품질 규칙) |
| ③ 원본 변환 | 기존 결과 엑셀 → 원본 데이터 파일 (처음 1회) |

## 원본 데이터 파일 구조

| 시트 | 내용 |
|---|---|
| 공연목록 | 공연 1행 = 1줄. `attendance_label`(예: 소속사 제공)은 숫자 서식 괄호로 출력. `attendance_rule`은 원자료에서 attendance가 수용인원×일수 수식이던 행 표시. `집계묶음`은 공식누적과 연결 |
| 솔로부록 | 본문 뒤에 붙는 솔로 공연(순서 그대로) |
| 공연장마스터 | location·city·capacity·source. **source를 적은 공연장만** 빈 capacity를 채우는 데 쓰임 |
| 공식누적 | 공연장별 수치는 없고 합계만 공식 발표된 경우(예: 돔 4회 합계 17만). 순위 산정 때 묶음 합계를 한 번만 더함 |
| 연도별목록 / 변수설명 | 결과 엑셀에 그대로 들어감(자동 순위 연도 행만 다시 씀) |
| 설정 | 기준일, 자동순위연도, 상위N |

## 업데이트 파일

'업데이트' 시트 한 행 = 작업 하나. `작업` 열에 추가 / 수정 / 삭제.
- 추가: 새 공연. gender~agency3가 비면 같은 아티스트 기존 행에서 복사
- 수정: `대상_start_date`·`대상_location`으로 기존 공연을 찾아 값을 적은 칸만 바꿈. `(비움)`은 칸 비우기, `+ 내용`은 기존 글 뒤에 덧붙이기
- 삭제: 대상 공연 삭제
- '공식누적' 시트: 같은 집계묶음이면 덮어쓰기
- `대상시트` 열(맨 오른쪽): 비우면 공연목록, `솔로부록`이면 솔로부록 행을 추가·수정·삭제 (추가 행은 같은 아티스트 블록 안 날짜 자리에 들어감)
- '목록' 시트: 연도별 아티스트 목록 고치기. 열 `작업 | year | 순위 | 찾을 문구 | 값 | 근거`
  - `SUB추가` / `SUB삭제`: 비고 오른쪽 SUB 칸(S열부터, 2024 IU처럼)
  - `비고교체` / `비고덧붙이기` / `비고바꾸기`(찾을 문구 → 값)
  - `순위교체`(그 자리 팀을 바꾸고 밀린 팀은 SUB로) / `순위넣기`(그 자리에 넣고 아래 팀을 내림, 15위였던 팀은 SUB로) — 자동 순위 연도에는 쓸 수 없음
  - 자동 순위 연도에서 SUB 팀이 상위 N팀에 들면 결과 엑셀 SUB 칸에서 자동으로 빠짐
- '공연장마스터' 시트: `작업(추가/수정/삭제) | location | city | country | capacity | source | 근거`. location+city로 찾음
- 시트는 필요한 것만 있으면 됨(옛 업데이트 파일도 그대로 동작)

①에서 원본 + 업데이트를 같이 올리면 변경 내역표가 나오고, `새 원본 받기`로 합쳐진 최신 원본을 받아 다음 업데이트에 씀.

## 순위 산정 규칙

1. 공식누적 묶음 → 공식 합계
2. 그 외 행 → attendance(공식 관객수), 없으면 capacity × days
3. 수치가 둘 다 없는 행은 0으로 계산되고 화면에 '수치 없는 행'으로 표시

## 변경 (2026-10-27)

- 기능 소개의 1~3단계 번호·제목을 버튼으로: 누르면 그 단계 스크롤 위치로 이동해 설명과 데모가 바뀜. 모바일도 세 단계가 모두 보이고 누를 수 있음

- 화면 문장 어미를 해요체로 통일 (라벨·규칙 이름은 명사형 유지)

- 기능 소개의 "바로 쓰기"를 큰 버튼으로 바꾸고, 옆에 "계속 내리면 다음 기능" 안내 추가
- 기능 소개 구간에서만 화면 아래에 따라다니는 바로가기(지금 보는 기능 + 진행 점 + 바로 쓰기) 추가. 모바일은 이것 하나만 표시
- 바로 쓰기·탭·상단 버튼으로 이동하면 도착한 도구 카드에 잠깐 파란 테두리, 키보드 포커스도 도구 제목으로 이동

- 상단 바에 다크/라이트 전환 스위치 추가. 선택은 브라우저에 저장되어 다시 열어도 유지 (`data-theme="light"`, 색은 `css/app.css` 상단 토큰)
- 기능 소개 챕터 스크롤 길이 단축(340vh → 210vh), 전환 애니메이션 단축
- **한 페이지 스크롤 구성 (스크롤 스토리텔링)**
  - 히어로 → 소개 문장(스크롤에 따라 어절이 밝아짐) → 기능 소개 챕터 3개 → 실제 도구 3개 → 마무리 순서.
  - 기능 소개 챕터는 화면이 고정된 채 스크롤에 맞춰 "무엇을 하는지·어떻게 쓰는지" 3단계와 데모 화면이 바뀜.
  - 상단 탭은 해당 기능으로 스크롤 이동하고, 스크롤하면 지금 보는 기능에 탭 표시가 따라옴.
- **디자인**: 다크 차콜(#121212) + 포인트 블루 #01539F. 글자로 쓰는 블루는 대비를 위해 같은 계열의 밝은 톤(#5B9FE3). 영문·숫자는 Poppins, 한글은 Pretendard.
- **파일 구조**: `css/app.css`(디자인), `js/app.js`(도구 동작), `js/story.js`(스크롤 연출). 검증·조립 로직(`checker.js`, `assembler.js`)은 그대로.
- **접근성**: 드롭존 키보드(Enter/Space) 열기, 파일 상태 표시(성공 초록·실패 빨강), 기기의 "동작 줄이기" 설정 시 스크롤 연출 없이 정적 화면.
- **버그 수정 (assembler.js)**: '연도별목록' 시트의 사용 범위가 A1로 기록된 파일(예: openpyxl로 저장)에서 목록을 한 칸 밀려 읽어, 기존 순위 비교가 전부 "신규"로 나오고 2026 목록 자동 갱신이 빠지던 문제를 고침.
